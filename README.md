# PyDep — образовательная платформа

**Сайт:** [https://pydep.ru](https://pydep.ru) (HTTPS, Let's Encrypt)

PyDep — веб-платформа на Django для публикации и прохождения курсов, работы репетиторов со студентами и создания интерактивных учебных материалов.

## О проекте

Платформа объединяет три рабочих пространства:

- **PyDep** — каталог курсов, уроки, профиль ученика, Python Playground с проверкой заданий
- **Studio** — редактор курсов и уроков для авторов
- **Tutor** — кабинет репетитора: расписание, домашние задания, студенты, финансы

Контент уроков хранится в формате **Editor.js** (блочный JSON): заголовки, списки, код, цитаты, таблицы, чеклисты, изображения. Для практических заданий по Python используется встроенная песочница на **Pyodide** с изолированным выполнением кода в iframe и серверной проверкой ответов.

## Стек технологий

| Компонент | Технология |
|-----------|------------|
| Backend | Python 3.10, Django 4.2 |
| База данных | PostgreSQL |
| API | Django REST Framework |
| Редактор контента | Editor.js |
| Python Playground | Pyodide, CodeMirror |
| Изображения | Pillow, sorl-thumbnail |
| Сервер приложений | Gunicorn |
| Веб-сервер | Nginx |
| Контейнеризация | Docker |
| HTTPS | Let's Encrypt (certbot) |
| Frontend | HTML, CSS, JavaScript |

## Основные возможности

### Курсы и обучение
- Курсы, модули и уроки с человекочитаемыми URL (slug)
- Поиск по курсам, прогресс прохождения
- Практические задания с автоматической проверкой
- Python Playground — запуск кода в браузере без установки Python

### Studio — редактор для авторов
- Создание и структурирование курсов (модули, уроки)
- Блочный редактор Editor.js с загрузкой изображений
- Управление практическими заданиями к урокам

### Tutor — кабинет репетитора
- Расписание занятий
- Домашние задания и файлы проектов
- Список студентов, финансы
- Группы доступа к материалам

### Пользователи и платформа
- Регистрация, авторизация, аватары
- Регистронезависимый вход по логину
- Светлая и тёмная тема интерфейса
- Кастомные страницы ошибок (403, 404, 500)
- REST API для интеграций

## Архитектура приложения

```
pydep/
├── lesson/           # Курсы, уроки, playground, профиль
├── course_editor/    # Studio — редактор курсов
├── tutor/            # Кабинет репетитора
├── users/            # Пользователи и аутентификация
├── api/              # REST API
├── core/             # Общие компоненты
├── static/           # CSS, JS, изображения
├── media/            # Загруженные файлы
└── templates/        # HTML-шаблоны
```

## Модули Django

| Приложение | Назначение |
|------------|------------|
| `lesson` | Курсы, модули, уроки, playground, главная и профиль |
| `course_editor` | Studio: CRUD курсов, Editor.js, загрузка изображений |
| `tutor` | Расписание, ДЗ, проекты, финансы |
| `users` | Регистрация, вход, профиль пользователя |
| `api` | REST endpoints |

## Инфраструктура

Продакшен развёрнут на **pydep.ru**: Django в Docker, Nginx и PostgreSQL на сервере, статика и медиа отдаются через Nginx. Соединение защищено **HTTPS** сертификатом **Let's Encrypt** с автоматическим продлением.

# 🎓 PyDep — Образовательная платформа

PyDep — это веб-приложение, разработанное на Django, предназначенное для публикации, редактирования и управления образовательным контентом. Платформа поддерживает регистрацию пользователей, JWT-аутентификацию, визуальное редактирование материалов и масштабируемую архитектуру с использованием Docker и CI/CD.

## 🔗 Ссылка на проект

[pydep](https://pydep.ru)

## ⚙️ Стек технологий

- **Язык программирования:** Python 3.12
- **Веб-фреймворк:** Django 4.2
- **База данных:** PostgreSQL
- **API и аутентификация:** Django REST Framework, Djoser, SimpleJWT
- **Редактор контента:** django-ckeditor-5
- **Обработка изображений:** Pillow, sorl-thumbnail
- **Дополнительные библиотеки:** widget_tweaks, transliterate, requests
- **Сервер приложений:** Gunicorn
- **Веб-сервер:** Nginx
- **Контейнеризация:** Docker
- **CI/CD:** GitHub Actions
- **Фронтенд:** HTML, CSS

## 🧩 Основные функции

- Регистрация и аутентификация пользователей с использованием JWT
- Создание, редактирование и удаление образовательных материалов
- Визуальный редактор контента с поддержкой изображений
- Система комментариев для взаимодействия пользователей
- Панель администратора для управления пользователями и контентом
- API для интеграции с внешними сервисами и приложениями
- Поддержка загрузки и отображения изображений с генерацией миниатюр
- Контейнеризация приложения с использованием Docker
- Автоматизация процессов развертывания с помощью GitHub Actions
